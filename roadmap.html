Official Blueprint & Technical Specification

MakuluLinux Game Studio

A high-performance, cross-platform 3D Game Engine and Next-Gen Editor built on the open-source PlayCanvas engine. Designed with a familiar, battle-tested interface for game developers, an intuitive beginner mode for newcomers, and deep autonomous AI agent integration capable of constructing scenes, writing code, and orchestrating full game production.

01

Strategic Vision & Core Pillars

PlayCanvas pioneered browser-based WebGL/WebGPU 3D rendering with an ultra-lightweight footprint and instant multi-platform execution. However, while their runtime engine is open-source, their world-class graphical editor is closed-source and hosted in a proprietary cloud. MakuluLinux Game Studio breaks this barrier by providing an open, locally owned, cross-distro editor that pairs AAA web-standards rendering with bleeding-edge AI co-pilots.

🎮

Industry-Familiar Workflow

Designed specifically to feel natural to seasoned developers migrating from Unity, Unreal, and the PlayCanvas web editor. Zero friction in muscle memory.

🌱

Dual-Tier Interface

One-click instant toggle between Simple Mode (for hobbyists, students, and beginners) and Pro Mode (for technical artists and AAA programmers).

🧠

AI-Native Architecture

Not just an LLM chatbox, but a unified transactional Command Bus where autonomous AI agents can execute every single editor action, from level design to bug fixing.

🌐

Ubiquitous Compatibility

Works natively across every Linux distribution (Ubuntu, Debian, Fedora, Arch, MakuluLinux), Windows, macOS, and pure Web browsers without rewriting code.

02

Cross-Platform GUI Framework: Electron vs Qt vs Web

To guarantee seamless execution across every Linux distro (Ubuntu, Debian, Mint, Fedora, Arch, Cinnamon, GNOME, KDE, XFCE), as well as Windows and macOS, we evaluated the primary GUI architectures:

Criteria Qt 6 (C++ / QML) GTK 4 (C / Rust) Electron + Web Components (Recommended)
Linux Distro Universality Good, but library version mismatches (libstdc++, Qt ABI breaks) across distros often break apps. Poor portability on non-GNOME desktops and severe packaging headaches on Arch/Fedora/Debian. 100% Perfect Bundled Chromium runtime guarantees identical execution on all distros via AppImage/deb/rpm.
Engine Integration Difficult. Requires embedding QWebEngineView with multi-process IPC lag to PlayCanvas WebGL/WebGPU. Extremely difficult. No native WebGPU/WebGL canvas without heavyweight webkitgtk bridging. Zero-Overhead Native PlayCanvas runs directly inside the same V8/GPU process as the UI. Direct DOM/JS binding.
Windows & macOS Support Supported, but requires native platform compilers and custom toolchains for each OS. Poor native look and feel on Windows/macOS; difficult cross-compilation. Native 1-Click Build Electron-builder outputs `.exe`, `.dmg`, and Linux AppImages from a single codebase.
Web / Cloud Deployment Impossible without full WebAssembly rewrite of GUI. Impossible. Desktop only. Dual Target The exact same editor runs both as an offline desktop app AND a self-hosted cloud web app!
PlayCanvas PCUI Compatibility Requires rewriting all PlayCanvas UI widgets in QML. Requires rewriting all widgets in GTK XML. 100% Native Directly utilizes PlayCanvas's official open-source @playcanvas/pcui component system.
Architectural Decision: Dual Web + Electron Core

We build the editor using Vite + PlayCanvas PCUI + Modern Web Standards, wrapped in an Electron desktop shell. This gives us:
1. Single codebase: A single codebase that packages into a standalone Linux AppImage/deb (runs on ANY Linux distro out of the box), Windows installer, macOS package, AND a pure Web application that can be served via FastAPI/Nginx.
2. Zero IPC overhead: The PlayCanvas 3D scene and the Editor UI share the same JavaScript runtime memory space, meaning zero latency when inspecting thousands of entities.

Dual-Tier UX: Simple Mode vs Advanced Pro Mode

To satisfy both complete beginners who want to build games without writing complex code and veteran developers building complex AAA systems, the editor features an instantaneous Simple / Pro Mode Switcher on the top navigation bar.

🌱 Simple Mode (Novice & Indie)

Beginner Friendly

Goal: Zero intimidation. Build playable 3D games within minutes.

  • Simplified Inspector: Only displays intuitive properties (Position, Size, Look, Speed, Health, Jump Height). Complex matrices and quaternion math are hidden.
  • No-Code Behavior Cards: Attach pre-built logic: "WASD Character Movement", "Follow Camera", "Spin When Touched", "Patrol Between Points".
  • 1-Click Asset Spawner: Click to drop pre-rigged characters, trees, cars, weapons, and platforms with physics already pre-configured.
  • AI Prompt-to-Action Bar: Large, prominent prompt bar where the user can simply type: "Make this car drive faster" or "Add 10 coins in a circle".
  • 1-Click Play & Share: Immediate playtesting without compiling, with instant web export URL generation.

⚡ Pro Mode (AAA & Technical)

Advanced Developer

Goal: Unrestricted power and complete control over the entire engine.

  • Raw ECS Component Control: Full access to custom render passes, layer masks, batch groups, and custom shader chunks.
  • Embedded Monaco Code Editor: Full VS Code-grade code editing with TypeScript/JavaScript autocompletion for the entire pc.* engine namespace.
  • Full Physics Rigging: Ammo.js compound collision meshes, kinematic controllers, raycasting masks, and linear/angular constraints.
  • Performance Profiler: Real-time graphs for GPU draw calls, VRAM usage, shader compilation times, and memory allocations.
  • Post-Processing & Shaders: Direct authoring of custom WGSL/GLSL shaders, SSAO, SSR, Bloom, and ACES Color Grading.

AI-First Engine: Deep Multi-Agent Autonomous Studio

Most AI integrations in editors are basic chatbots that merely give advice. In MakuluLinux Game Studio, the AI is an Active Co-Creator. The entire editor is engineered around the Universal Command Bus, enabling autonomous AI agents to execute any action a human can perform.

MakuluLinux AI Backend Details

• Endpoint: https://makululinux.us:2007/v1/chat/completions
• Primary Models: electra (complex reasoning & script synthesis) and electra-nano (rapid sub-second scene commands)
• Authentication: Auto-detected from ~/.config/ai_terminal/electra_auth.json or user API key via AI Settings
• Quota: Unlimited generations enabled on Electra models.

Asset Ecosystem, Free 3D Model Stores & Terrain

A game engine is only as good as its asset pipeline. PlayCanvas natively utilizes glTF 2.0 / GLB, the industry-standard "JPEG of 3D". MakuluLinux Game Studio integrates direct access to premier free model repositories, procedural terrain generators, and ready-to-play templates:

🍕

Poly Pizza Direct Integration

Integrated in-editor search and 1-click import for thousands of free low-poly CC0 3D models with instant GLB download and attribution metadata.

📦

Kenney.nl CC0 Starter Kits

Pre-bundled library of hundreds of modular game-ready models: Medieval Castle, Sci-Fi Space Kit, City Kit, Nature Pack, and Vehicle Kit—royalty free for any commercial use.

🏞️

Poly Haven & ambientCG (PBR Materials)

Direct download of 1K/2K/4K PBR textures (Diffuse, Normal, Roughness, Ambient Occlusion, Displacement) and high dynamic range 360° HDRI skyboxes.

🏃

Rigged Characters & Animations

Pre-rigged humanoids with standard Mixamo / GLTF skeletal hierarchies and pre-baked animation sets (Idle, Walk, Run, Jump, Attack, Die).

Procedural 3D Terrain Generator

Instead of requiring external tools like Blender just to make a mountain or valley, MakuluLinux Game Studio includes a built-in Heightmap & Terrain Sculptor:

  • Procedural Perlin / Simplex Noise: Generate realistic mountain ranges, rolling hills, canyons, and plains with adjustable octaves, frequency, and persistence.
  • Real-time Brush Sculpting: Raise, Lower, Smooth, and Flatten brushes with radius and falloff control directly inside the 3D viewport.
  • Splatmap Multi-Texture Blending: Automatically blend Grass on flat surfaces, Rock on steep cliff angles, and Snow at high altitudes via GPU shaders.
  • Automatic Collision Generation: Instant conversion of terrain height fields into static Ammo.js physics collision shapes.

AAA-Grade Rendering Pipeline

Leveraging the latest capabilities of the local PlayCanvas engine (v2.24+), MakuluLinux Game Studio delivers graphical fidelity comparable to desktop engines while maintaining high framerates across low-end and high-end hardware:

⚡ WebGPU & WebGL2 Next-Gen API

WebGPU compute shaders, bind groups, and indirect drawing alongside rock-solid WebGL2 fallback for 100% device coverage.

💡 Clustered Lighting Pipeline

Render hundreds of dynamic point and spot lights simultaneously with minimal performance cost via GPU clustered light culling.

✨ Physically Based Rendering (PBR)

Full support for Metallic-Roughness, Anisotropy, Sheen, Clearcoat, Transmission (glass/refraction), and Subsurface Scattering.

🎥 Cinematic Post-Processing Stack

Built-in Screen-Space Ambient Occlusion (SSAO), HDR Bloom with threshold curves, Screen-Space Reflections (SSR), Depth of Field bokeh, and ACES Tonemapping.

☁️ 3D Gaussian Splatting

Native rendering of photo-realistic 3D Gaussian Splats directly in the editor, allowing real-world scans to be placed into games.

🌑 Cascaded Shadow Maps (CSM)

Ultra-crisp directional shadows with seamless distance fading, soft PCF filtering, and contact shadow approximation.
