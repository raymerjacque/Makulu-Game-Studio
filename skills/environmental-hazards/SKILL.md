# Environmental Hazards Skill

## 🎯 When to Use This Skill
Use this skill for death pits, molten lava floors, poison swamps, or spike gauntlets.

## 🔑 Key Concepts & Architecture
- Behavior: `lava_hazard`.
- Actions: `create_hazard_zone`.
- Deals lethal or continuous damage on contact, triggers camera shake, and plays explosion SFX.
