# Quest and Dialogue System Skill

## 🎯 When to Use This Skill
Use this skill for RPG adventures, talking NPCs, story cutscenes, and quest objectives.

## 🔑 Key Concepts & Architecture
- Behaviors:
  - `dialogue_system`: Displays dialogue modal when player interacts with NPC.
  - `quest_tracker`: Displays active quest title, steps, and rewards on the HUD.
