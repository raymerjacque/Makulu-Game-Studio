# Inventory and Crafting Skill

## 🎯 When to Use This Skill
Use this skill for survival games, crafting benches, and item collection.

## 🔑 Key Concepts & Architecture
- Behavior: `inventory_crafting`.
- Tracks collected resources (wood, stone, iron) and crafts new items (tools, weapons, potions) upon recipe completion.
